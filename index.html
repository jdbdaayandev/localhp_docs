Build locally.
Understand every layer.

LocalPHP is a lightweight PHP framework designed for local application development. This guide covers the project structure, HTTP layer, routing, custom views, database tools, validation, sessions, and CLI commands present in the current source.

PHP 8.2+Composer / PSR-4MySQL / PDOCustom PHP templatesLocal development focus
Version note. The inspected source identifies itself as LocalPHP 0.2.0 and is actively evolving. This documentation describes the source snapshot it accompanies; confirm behavior against your current working copy if you have made later changes.

How to use this documentation

Each chapter has its own HTML page. Use the sidebar search to find a topic, navigate between chapters with the previous/next links, or open the table of contents below. The files work locally without a web server or external JavaScript/CSS libraries.

Implementation note: Examples describe the documented framework API, but always check the feature-status chapter for items that are partial or not yet verified in your current project copy.
