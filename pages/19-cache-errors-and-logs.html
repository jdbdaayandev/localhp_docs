19. Cache, errors, and logs

Configuration cache

Configuration caching is implemented through a generated PHP file, not a general-purpose data cache:

php local config:cache
php local config:clear

The runtime configuration helper reads storage/cache/config.php when present. Rebuild the cache after changing configuration files or values that are baked into the cache.

Exception logs

The web exception handler registers PHP error, uncaught exception, and shutdown handling. It writes exception details to a daily file such as storage/logs/localphp-YYYY-MM-DD.log and falls back to PHP's error_log() if writing fails. When debug mode is disabled, the web exception page is intended to hide detailed exception information from visitors.

Implemented in source: configuration-file caching and web exception logging.
Not the same as a complete cache/logger service. The current source does not establish a general cache API with TTL/invalidation for arbitrary application data, nor a verified logger facade with methods such as logger()->info(). Route caching is not documented as available.
