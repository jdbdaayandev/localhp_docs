15. Models / ORM

Models extend LocalPHP\Model\Model. Set the table explicitly when needed and define mass-assignable fields with $fillable.

<?php
declare(strict_types=1);

namespace App\Models;

use LocalPHP\Model\Model;

final class Product extends Model
{
    protected string $table = 'products';
    protected array $fillable = ['name', 'sku', 'price', 'stock'];
}

Common operations

$all = Product::all();
$product = Product::find(1);
$matching = Product::where('active', 1)->get();
$count = Product::count();

$product = Product::create([
    'name' => 'Brake Pad',
    'sku' => 'BP-001',
    'price' => 350,
    'stock' => 12,
]);

$product->price = 375;
$product->save();
$product->delete();

Model methods include query, all, find, where, orderBy, create, firstOrCreate, count, fill, getAttribute, setAttribute, getAttributes, toArray, save, delete, exists, getTable, and getKeyName.

ORM scope. This is a lightweight custom ORM, not a feature-complete Active Record package. Do not assume relationships, eager loading, scopes, events, casts, or soft-delete filtering exist unless present in the source.
