18. CLI command reference

Run commands from the project root using php local <command>.

CommandDescription
php local / php local listDisplay available commands.
php local aboutDisplay framework information.
php local make:controller HomeCreate a controller.
php local make:model ProductCreate a model.
php local make:filter UserFilterCreate a filter class.
php local make:validator UserCreate a validator scaffold.
php local make:middleware AuthCreate a middleware scaffold.
php local make:migration create_products_tableCreate a migration.
php local migrateRun pending migrations.
php local migrate:statusShow migration status.
php local migrate:rollbackRoll back the latest migration batch.
php local migrate:fresh --forceDrop tables and rerun migrations; destructive.
php local make:seeder ProductSeederCreate a seeder.
php local db:seedRun the default seeder.
php local db:seed ProductSeederRun a named seeder.
php local config:cacheCompile configuration into storage/cache/config.php.
php local config:clearRemove compiled configuration.
php local optimizePrepare configuration cache; also prints guidance about PHP OPcache.
php local optimize:clearClear framework cache files.
php local cleanClear cache and logs.
php local clean:cacheClear cache files.
php local clean:logsClear log files.

The CLI's exact command set is defined in framework/src/Console/Kernel.php. If a command is absent in your working copy, check php local list.
