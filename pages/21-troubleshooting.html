21. Troubleshooting

Composer class not found

composer dump-autoload

Check namespace and file path. LocalPHP\ maps to framework/src/; App\ maps to app/.

404 - Page Not Found

  • Confirm the route exists in routes/web.php.
  • Check the HTTP method and URI, including any subfolder/base path.
  • Check that the web server points to the expected project entry point and rewrite rules are enabled.
  • Ensure the application boots and route definitions load successfully.

MySQL connection refused

  • Start MySQL in Laragon.
  • Verify host, port, database name, username, and password in .env.
  • Create the database before migrations.
  • Ensure the PDO MySQL extension is enabled in the PHP version used by both Apache and CLI.

View not found

Check that the view exists under resources/views/ and the name matches the file path. For example, view('home') maps to resources/views/home.php.

Configuration changes seem ignored

php local config:clear
php local config:cache

Clear the cache first when testing uncached values. Rebuild it after final changes if you want cached configuration enabled.

Log file missing

Trigger an error only in a safe local test, then check storage/logs/. Verify that the directory is writable by the PHP process. If the log write fails, the handler attempts to use PHP's error log.
