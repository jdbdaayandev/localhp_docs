14. Query builder reference

Start with DB::table('table_name') or a model's query() method. Builder calls are chainable. Values should be passed through builder parameters instead of concatenated into SQL.

Selecting and retrieving

$rows = DB::table('products')->select('id', 'name', 'price')->get();
$product = DB::table('products')->where('id', 10)->first();
$product = DB::table('products')->find(10);
$names = DB::table('products')->pluck('name');
$price = DB::table('products')->where('id', 10)->value('price');
$count = DB::table('products')->count();

Filters and conditions

Supported methods include where, orWhere, whereColumn, whereIn, orWhereIn, whereNotIn, orWhereNotIn, whereBetween, orWhereBetween, whereNotBetween, orWhereNotBetween, whereNull, orWhereNull, whereNotNull, orWhereNotNull, whereDate, whereTime, whereYear, whereMonth, whereDay, whereLike, whereNotLike, whereRaw, orWhereRaw, whereNested, whereExists, orWhereExists, whereNotExists, and orWhereNotExists.

$products = DB::table('products')
    ->where('active', 1)
    ->where(function ($query) {
        $query->where('stock', '>', 0)
              ->orWhere('allow_backorder', 1);
    })
    ->get();

Joins, grouping, ordering

Join methods: join, leftJoin, rightJoin, crossJoin, joinSub, leftJoinSub. Grouping and aggregation methods include groupBy, groupByRaw, having, orHaving, havingRaw, sum, avg, min, max, exists, and doesntExist.

$totals = DB::table('order_items')
    ->select('product_id')
    ->selectRaw('SUM(quantity * unit_price) AS total')
    ->groupBy('product_id')
    ->having('total', '>', 1000)
    ->get();

Ordering and pagination-style limits

Use orderBy, orderByDesc, orderByRaw, latest, oldest, inRandomOrder, limit, take, offset, skip, and forPage.

Writes

DB::table('products')->insert([
    'name' => 'Spark Plug',
    'price' => 150.00,
]);

DB::table('products')->where('id', 10)->update([
    'price' => 175.00,
]);

DB::table('products')->where('id', 10)->delete();

The builder also provides insertGetId, upsert, increment, decrement, conditional chaining via when and unless, raw expressions, and SQL/binding inspection through toSql() and getBindings(). Confirm method signatures in framework/src/Database/QueryBuilder.php for less common operations.

Raw SQL caution. Bind user-controlled values. Raw SQL fragments and identifier names are not interchangeable with bound values. Never interpolate untrusted input directly into a raw SQL string.
