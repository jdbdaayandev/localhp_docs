Chapter 23

23. Feature status and boundaries

This section intentionally separates source-backed behavior from features that should not be assumed complete.

AreaStatus in inspected sourceNotes
Application bootstrap / HTTP request and responsePresentCore entry point, request object, response object.
Routing and controller dispatchPresentGET/POST/PUT/PATCH/DELETE/any, route parameters, groups and named URL generation are present in the Router source.
Custom views and helpersPresentPHP-based custom template engine; not full Laravel Blade compatibility.
Environment/configurationPresentEnvironment loader and dot-key configuration helper.
Configuration cachePresentCompiled config PHP file and CLI clear/cache commands.
Web exception loggingPresentDaily log files with PHP error-log fallback; verify permissions at runtime.
Query builder and PDO MySQLPresentLarge set of query, join, aggregate, and write methods. Run integration tests against your DB.
Basic ORM/model layerPresentCRUD-style methods; do not assume advanced ORM relations/features.
Schema builder / migrations / seedersPresentMySQL-focused; migration behavior and destructive paths should be tested.
ValidationPresentRule set listed in this guide; DB rules need connectivity.
General-purpose data cache with TTLNot verifiedConfiguration cache exists; a generic key/value cache API is not established by this source.
General logger APINot verifiedException logging exists; a full application logger facade is not established.
Route cache / compiled routesNot present in CLIDo not assume route caching is available.
Full production-hardening / middleware enforcementVerify separatelyCheck CSRF enforcement, filter pipeline, access restrictions, and deployment configuration.

Documentation prepared against the LocalPHP source snapshot available on 9 October 2026. Update this page as the implementation evolves.
