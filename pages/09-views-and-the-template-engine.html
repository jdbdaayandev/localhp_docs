9. Views and the template engine

View files live in resources/views/. The helper convention maps dot notation to nested directories: view('home') resolves resources/views/home.php, while view('layouts.app') resolves resources/views/layouts/app.php.

Render a view

return view('home', [
    'title' => 'Products',
    'products' => $products,
]);

Layout example

<!-- resources/views/layouts/app.php -->
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>@yield('title', 'LocalPHP')</title>
</head>
<body>
  <main>@yield('content')</main>
</body>
</html>

Template directives

SyntaxPurpose
{{ $value }}Escaped output.
{!! $html !!}Raw HTML output; only use trusted or properly sanitized content.
@extends('layouts.app')Choose a layout.
@section('content') / @endsectionDefine a section.
@yield('content')Output a section in a layout.
@include('partials.header')Include another view.
@if, @elseif, @else, @endifConditional rendering.
@foreach, @endforeach, @for, @endfor, @while, @endwhileLoops.
@break, @continueLoop control.
@php / @endphpExecute a PHP template block.
Important: This is LocalPHP's custom template engine, not Laravel Blade. Directive behavior and edge cases depend on framework/src/View/Local.php. Do not assume all Laravel Blade features exist.
