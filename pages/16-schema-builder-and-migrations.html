16. Schema builder and migrations

Schema builder

LocalPHP\Database\Schema supports creating, altering, and dropping MySQL tables from PHP code.

use LocalPHP\Database\Schema;
use LocalPHP\Database\Blueprint;

Schema::create('products', function (Blueprint $table): void {
    $table->id();
    $table->string('name', 150);
    $table->string('sku', 60);
    $table->decimal('price', 10, 2);
    $table->integer('stock')->default(0);
    $table->timestamps();
    $table->unique('sku');
});

Column helpers in the current source include id, bigIncrements, increments, string, char, text, mediumText, longText, integer, bigInteger, tinyInteger, boolean, decimal, float, double, date, dateTime, timestamp, json, timestamps, and softDeletes. Index helpers include index, unique, primaryKey, and foreign. Column options are defined by ColumnDefinition; inspect that class for supported modifiers.

Migration class

Migration files are stored in database/migrations/ and use LocalPHP\Database\Migration:

use LocalPHP\Database\Migration;
use PDO;

return new class extends Migration {
    public function up(PDO $pdo): void
    {
        $pdo->exec('CREATE TABLE example (id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY)');
    }

    public function down(PDO $pdo): void
    {
        $pdo->exec('DROP TABLE IF EXISTS example');
    }
};

Generate a migration with php local make:migration create_products_table, then edit its up() and down() methods to define the schema.

Destructive commands. php local migrate:fresh --force drops and recreates migration-managed tables. Use only when you intend to reset the database and have a backup if the data matters.
